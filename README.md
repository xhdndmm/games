# games

一些小游戏，使用纯前端实现（html+css+js）并完全开源

## 游玩
网页托管于`https://game.xhdndmm.net`并由[Github Page](https://docs.github.com/en/pages)驱动

## 游戏列表
- 俄罗斯方块
- 五子棋
- 贪吃蛇

## 问题反馈
[Github Issues](https://github.com/xhdndmm/games/issues)

## 贡献说明
如添加新游戏，请以以下格式创建新游戏目录并在[PR](https://github.com/xhdndmm/games/pulls)中说明游戏名称
```
games/
  游戏英文名称/
    js/
    css/
    img/
    audio/
    index.html
```
